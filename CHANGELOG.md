# Changelog

## 1.0.0

First public beta.

- Desktop with draggable windows, taskbar, Start menu and right-click menus
- Apps: Notepad, Calculator, Clock, Paint, Browser, Task Manager
- BrowStore: Discover, BrowOS Apps, Library, add any website
- Floating windows for sites that can't be embedded
- Personalization: wallpapers, accent color, theme, corners, window buttons, transparency, cursor
- Update reminder for manual installs
